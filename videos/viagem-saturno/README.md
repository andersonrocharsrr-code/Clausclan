# Viagem até Saturno (~61 s)

Três cenas, juntadas com transições:
1. Dobra espacial (riscos de luz), Andrômeda passando pela esquerda, mergulho na Via Láctea (galáxias desenhadas).
2. Sistema Solar: Sol, Terra e Marte (fotos), cinturão de asteroides (foto do Phobos), Saturno (foto do Hubble) crescendo.
3. Saturno de perto (foto enviada), aproximação lenta com leve turbulência.

- Gerar uma cena: `node render.js saida.mp4 <cena> 1080 30` (pedaços com `INI`/`FIM`)
- Testar quadros: `node render.js teste.png 2 540 30 "1,10,20"`
- Som: `python3 audio.py som.wav`
